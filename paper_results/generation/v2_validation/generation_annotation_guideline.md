# 生成回答双人盲评指南

## 目的
对医疗 RAG 生成端回答进行独立的双人（A/B）盲评。两位标注者互不交流，独立对每个 answer_id 打分。

## 盲评原则
1. 表中只含 `answer_id`、问题、证据与模型回答，**不含任何方法名/条件名**（B0/D0/D3 均不可见）。
2. 两位标注者不得在完成全部打分前互相讨论。
3. 所有评分字段**必须由人工填写**，任何自动化评分均无效。
4. 若回答为空（当前生成被阻塞），请将各评分字段留空并在 notes 标注“未生成”。

## 字段定义

| 字段 | 取值 | 定义 |
|------|------|------|
| faithfulness_0_1_2 | 0/1/2 | 回答是否忠实于证据：0=编造/矛盾，1=部分支持，2=完全由证据支持 |
| answer_relevance_0_1_2 | 0/1/2 | 回答与用户问题的相关程度 |
| demand_completeness_0_1_2 | 0/1/2 | 回答覆盖用户全部信息需求的完整度 |
| unsupported_claim_0_1 | 0/1 | 是否存在证据不支持的主张（0=无，1=有） |
| critical_risk_omission_0_1 | 0/1 | 是否遗漏了证据中出现的重大安全风险（0=无遗漏，1=有遗漏） |
| overall_utility_0_1_2 | 0/1/2 | 整体有用性（考虑准确性、完整性、安全性） |
| notes | 文本 | 任何补充说明，如“证据不足”“有歧义” |

## 流程
1. 标注者 A、B 分别打开 `generation_annotation_A.csv` / `generation_annotation_B.csv`。
2. 阅读问题与证据，阅读模型回答，逐项打分。
3. 完成后回传；研究者将计算两位标注者的一致性（如 Cohen's kappa）并仲裁分歧。
